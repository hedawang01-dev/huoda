# 活搭 HUODA 5.4 升级与验收报告

日期：2026-09-12

## 升级结果

本次在 5.3 基线上做增量升级，没有更换技术栈或重做页面。顶部搜索、通知入口调整、对话返回、移动底栏、PC 顶部导航和原有视觉样式均保留。新增工作集中在数据边界、业务状态、云端迁移、审核后台与生产部署。

## 已解决的检查项

## 数据与权限边界

- 用户、资料、任务、报名、收藏、消息、通知、评价、举报、认证和审计均已有 Supabase 表/RPC 路径。
- 关键状态写入通过受控 RPC，固定 search_path、显式鉴权并收回默认执行权限。
- 任务录用、取消和容量变化先锁任务再锁报名，避免超卖和反向锁顺序。
- 游客只能读取审核通过且可招聘的任务；个人数据依赖 RLS。
- 营业执照保存在私有 Storage；后台通过短时 signed URL 查看。
- 浏览器只接收 Project URL 与 publishable/anon key；构建扫描并拒绝高权限 key。
